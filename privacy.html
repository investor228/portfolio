Privacy Policy — gmail-mcp

Last updated: September 16, 2026

What this app is

gmail-mcp is a personal, non-commercial tool. It connects the Gmail account of its owner, Maksim Padleski, to an AI assistant running on the owner's own computer, so the owner can sort, search and draft replies to their own email. It is not offered to the public and is not intended for use by anyone else.

Data accessed

With the owner's consent, the app requests these Google OAuth scopes:

  • gmail.modify — read, search, label and draft messages in the owner's mailbox;
  • gmail.settings.basic — view and manage mail filters.

How data is used

  • Email data is used only to perform actions the owner requests: summarising the inbox, searching messages, preparing reply drafts and organising labels.
  • OAuth tokens are stored locally on the owner's computer and are never sent to any server other than Google.
  • When the owner asks the AI assistant (Claude, by Anthropic) to work with a message, the relevant email content is sent to Anthropic's API for processing, under Anthropic's terms and privacy policy.
  • Data is not sold, not used for advertising, and not shared with any other third party.
  • No email data is stored on this website or on any server operated by the owner.

Google API Services User Data Policy

The use and transfer of information received from Google APIs by this app adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time in Google Account → Third-party apps & services. Deleting the local token files removes all stored credentials.
